# 🧭 사회복지 현장 나침반 (`welfare-field-compass`)

사회복지 전공 대학생들이 **법령·소관부처별 사회복지기관 체계**, **현장실습 자가 탐색 및 법정 요건 준비**, **인턴·수련·졸업 후 취업처 탐색**, 그리고 **복지 시사 브리핑**까지 스스로 탐색하고 준비할 수 있도록 만든 통합 안내서 웹 플랫폼입니다.

---

## 1. 핵심 기능 & 4대 뷰 구조

1. **`view-fields` — 분야와 법령 (사회복지 법령별 · 12대 분야별 기관 도감)**
   - **1. 법정 시설 및 근거법령 분류표 (상단 컨트롤 바)**:
     - `📊 법령 매트릭스 표` ↔ `🗂️ 12대 분야 카드` 원클릭 보기 전환.
     - 소관부처별 원클릭 필터(보건복지부, 성평등가족부, 고용노동부, 교육부, 국가보훈부, 법무부 등) 및 생활시설/이용시설 형태 필터, 실시간 통합 검색창 제공.
   - **2. 소관부처 · 시설종류 · 생활/이용시설 · 근거법령 통합 분류표 (본문 컨테이너)**:
     - 울산사회복지협의회(`wel4u.or.kr`)의 4차원 분류표(소관부처 × 시설종류 × 생활/이용시설 × 근거법령)를 2026 현행 기준(**성평등가족부**, **가족센터 통합**, **교육부 유보통합**, **돌봄통합지원법**)으로 현대화한 24개 법정 시설 상세 표 & 모바일 반응형 카드.
     - 12대 실천 분야 카드 모드에서는 각 분야별 아이콘, 핵심 대상, 대표 취업처, 2학년 실습 추천 팁 및 상세 모달 제공.
   - **3. 원클릭 소관부처별 법령 비교 매트릭스 (맨 밑 배치 & 경량화)**:
     - 6대 소관부처(복지부, 성평등가족부, 노동부, 교육부, 보훈부, 법무부)의 심층 법령 비교 카드를 **본문 최하단으로 재배치**하고 **기본 상태를 세련된 경량 요약 배너로 접어두어 메인 화면 첫 진입 시 전혀 무겁지 않게 구성**.
     - 클릭 시 원클릭으로 부드럽게 펼쳐지며, 상단 빠른 안내 배너의 `1️⃣ 법령·부처별 한눈에 비교 ↓`를 클릭하면 즉시 펼쳐지며 스크롤됩니다.

2. **`view-practicum` — 대학생 현장실습 자가탐색 허브**
   - **STEP 1. 성향·관심사 자가진단 (4문항)**: 관심 대상·희망 환경·강점·진로 목표 선택 시 12대 분야 중 맞춤 TOP 3 실습 분야를 추천합니다.
   - **STEP 2. 12대 분야별 실습 가이드**: 실제 실습 과업, 선수과목, 모집 시기, 합격 팁 비교 및 희망 실습기관 메모 저장.
   - **📢 2026 대학생 실습생 모집 공고 & 실습처 100+ DB (대폭 확장)**:
     - **103개 수도권 실습처 전수 등록**: 서울 25개 자치구 & 경기 주요 시·군을 100% 커버하는 12대 복지분야 공식 실습 공고 DB 구축.
     - **2단계 정밀 지역 필터**: 1차 광역(`전체` / `📍 서울특별시` / `📍 경기도`) + 2차 자치구·시군 드롭다운(`강남구`, `노원구`, `수원시`, `성남시` 등 구/시별 실시간 카운트 제공).
     - **실습비 부담 완화 필터**: `전체 실습비`, `💎 무료 실습처 (25개처)`, `🏷️ 5만원 이하 (48개처)`, `🏷️ 10만원 이하 (103개처)`.
     - **학기 & 12대 분야 원클릭 칩**: 하계/동계/학기중 계절 필터 + 12대 복지 분야별 원클릭 필터링.
     - **스마트 8개 카드 페이지네이션**: 카드 디자인의 직관성과 가독성을 유지하며 `[< 이전] [1] [2] ... [n] [다음 >]` 번호 네비게이션 및 부드러운 스크롤 탑 지원.
     - **실습처 카드 스펙**: 일정, 실습비(중식/수당), 모집인원, 마감 D-Day 배지, 신청 요건, 전형 절차, 2학년 합격 팁, 공식 원문 링크, '내 준비함 실습처 찜' 완벽 연동.
   - **STEP 3. 법정 요건 체크리스트 & 공식 조회 연동**: 「사회복지사업법 시행규칙」 기준(160시간 + 세미나 30시간 + 선이수 요건) 자가 점검 및 한국사회복지사협회 실습기관 조회·복지넷·VMS 등 공식 포털 연동.

3. **`view-jobs` — 인턴 · 수련 · 졸업 후 취업처 & 수도권 실시간 공고**
   - **🌱 대학생 인턴·수련 vs 💼 신입·정규직 듀얼 히어로 토글 (신규)**: 2~3학년 대학생이 즉시 지원 가능한 방학 인턴/1년 전문 수련 공고와 4학년 졸업예정자용 정규직 채용을 대형 탭으로 명확히 분리.
   - **공고 카드 3대 스펙 & D-Day 하이라이트 (신규)**: 실시간 D-Day 뱃지, 필수 자격(1급/2급/수련), 급여 기준(2026 복지부 가이드라인/호봉제), 근무 권역 뱃지 제공.
   - **12대 분야 취업처 로드맵**: 분야별 진출 기관, 인턴/수련 루트, 2026년 보수 가이드라인 안내.
   - **개인 지원현황 트래킹**: 공고별 지원상태(관심→서류준비→서류제출→면접→합격)와 개인 메모를 `localStorage`에 격리 관리.

4. **`view-news` — 사회복지 & 공익 시사 브리핑**
   - **🏷️ 2026 복지 이슈 핵심 해시태그 아카이브 (신규)**: `#돌봄통합지원법`, `#유보통합`, `#고립은둔청년`, `#2026인건비가이드라인` 등 핵심 해시태그 칩을 클릭해 1초 만에 관련 시사를 필터링.
   - **💡 2학년 실습·면접 대비 체크포인트 (`studyTip`) 전면 강화**: 각 뉴스마다 전공 시험, 복지관 프로포절, 실습·면접에서 즉시 인용할 수 있는 고대비 콜아웃 박스 제공.
   - 개인 시사 노트 스크랩(`localStorage`) 지원.

5. **상시 `내 준비함` 슬라이드 서랍 (`workspace.js` + `storage.js`)**
   - 방문 대학생마다 브라우저 `localStorage`에 독립 저장되는 개인 준비 공간(찜한 분야·법령, 희망 실습·취업 기관 메모, 실습 체크리스트, 공고별 지원 상태 요약)과 JSON 백업/복원을 제공합니다.

```text
│   └── auto_scrape.py                # 수도권 세분화 분야 + 인턴/수련 공고 & 뉴스 동기화기
└── src/
    ├── styles/

    │   └── default-news.js           # 12대 분야 연계 & 실습·면접 포인트 시사 브리핑
    └── js/
        ├── app.js                    # 4대 뷰 전환, 크로스 뷰 연동, 공용 피드 구독 및 초기화
        ├── fields.js                 # View 1: wel4u형 법령 매트릭스 표 + 12대 분야 카드 + 상세 드로어
        ├── practicum.js              # View 2: 성향 자가진단 + 실습 가이드 + 법정 체크리스트
        ├── jobs.js                   # View 3: 12대 취업처 로드맵 + 수도권 공고·개인 지원트래킹
        ├── news.js                   # View 4: 복지 뉴스 필터·검색·개인 시사 스크랩

        ├── storage.js                # 개인 워크스페이스 localStorage 상태 관리 모듈

        ├── theme.js                  # 다크모드 / 라이트모드 전환
        └── utils.js                  # HTML XSS 이스케이프 & http/https URL 보정 유틸
```

## 3. 실행 및 테스트 방법

### 프론트엔드 실행
`<script type="module">` 구문은 로컬 HTTP 서버 또는 배포 호스팅 환경에서 실행하세요.

- **방법 A (Windows 원클릭)**: `run_local.bat` 더블클릭 → `http://localhost:8080` 자동 실행
- **방법 B (터미널)**:
  ```powershell
  python -X utf8 -m http.server 8080
  ```

### Python 수집기 점검
```powershell
pip install -r requirements.txt
python -X utf8 scripts/auto_scrape.py --dry-run
```
