<section class="scroll-mt-24 mb-space-xl" id="section-1">
<h2 class="font-headline-md text-headline-md text-[#F8FAFC] font-bold mb-space-md tracking-tight">
            1. 투명성과 설명 가능성: 인터페이스의 정직함
          </h2>
<p class="font-body-md text-body-md text-[#E2E8F0] leading-loose mb-space-md">
            생성형 인공지능이 도입되면서 제품 디자인의 본질은 “어떻게 클릭을 유도할 것인가”에서 “어떻게 기계의 불확실성을 투명하게 전달할 것인가”로 극적인 패러다임 전환을 겪고 있습니다. 과거의 소프트웨어는 결정론적(deterministic)이었습니다. 버튼을 누르면 정해진 논리 경로를 거쳐 예측 가능한 결과가 화면에 그려졌습니다. 그러나 확률적(probabilistic) 모델이 인터페이스의 엔진으로 자리 잡은 오늘날, 같은 입력에도 매번 상이한 결과가 도출될 수 있습니다.
          </p>
<p class="font-body-md text-body-md text-[#E2E8F0] leading-loose mb-space-lg">
            이러한 상황에서 디자이너가 저지르기 쉬운 가장 치명적인 실수는 결과를 마치 절대적인 정답인 양 완벽한 어조로 포장하는 것입니다. 정직한 인터페이스는 모델의 확신도(Confidence Score)를 지능적으로 시각화하고, 결론에 도달한 추론의 출처를 마이크로 인터랙션을 통해 즉각 검증할 수 있도록 지원해야 합니다.
          </p>
<!-- Pull Quote Block -->
<figure class="my-space-xl pl-space-md py-space-sm bg-[#161F30] rounded-r-xl border-l-[3px] border-blue-500 border-y border-r border-white/[0.06] shadow-lg">
<blockquote class="font-body-lg text-body-lg italic text-[#F8FAFC] leading-relaxed mb-2">
              “훌륭한 기술은 마법처럼 보이지만, 사용자가 진정으로 사랑하고 지속해서 신뢰하는 프로덕트는 언제나 정직하고 투명하게 동작한다.”
            </blockquote>
<figcaption class="font-label-sm text-label-sm text-slate-400 font-semibold">
              — 김서연, &lt;신뢰를 구축하는 AI 인터랙션 디자인&gt; 중에서
            </figcaption>
</figure>
<p class="font-body-md text-body-md text-[#E2E8F0] leading-loose">
            사용자는 자신이 통제할 수 없는 미지의 블랙박스를 마주했을 때 불안감을 느끼며 서비스를 이탈합니다. 출처 링크 스니펫, 검증용 토글, 생성 매개변수의 간소화된 슬라이더는 단순한 장식이 아니라 인간과 지능형 에이전트 간의 정서적 계약을 체결하는 필수 구조물입니다.
          </p>
</section>

<h2 class="font-headline-md text-headline-md text-[#F8FAFC] font-bold mb-space-md tracking-tight">
            2. 인지 부하를 줄이는 시각적 위계와 여백의 미학
          </h2>
<p class="font-body-md text-body-md text-[#E2E8F0] leading-loose mb-space-md">
            방대한 데이터가 초 단위로 쏟아질 때, 디자이너의 가장 강력한 무기는 역설적이게도 ‘여백’과 ‘절제’입니다. 모델이 수집하고 종합한 모든 변수를 화면에 나열하는 것은 사용자에게 가치 있는 정보를 주는 것이 아니라 인지적 피로를 가중시킬 뿐입니다.

<section class="scroll-mt-24 mb-space-xl" id="section-3">
<h2 class="font-headline-md text-headline-md text-[#F8FAFC] font-bold mb-space-md tracking-tight">
            3. 지속 가능한 피드백 루프와 사용자 제어권
          </h2>
<p class="font-body-md text-body-md text-[#E2E8F0] leading-loose mb-space-md">
            진정한 제품 경험의 완성은 시스템이 실수를 범했을 때 드러납니다. 인공지능이 부정확한 결과를 제시했을 때, 사용자가 이를 쉽게 교정하고 시스템에 피드백을 전달할 수 있는 메커니즘이 구비되어 있어야 합니다. 이른바 ‘우아한 오류 복구(Graceful Error Recovery)’ 설계입니다.
          </p>
<!-- Visual Graphic Callout with inline illustration -->
<div class="p-space-lg rounded-xl bg-[#161F30] border border-white/[0.08] my-space-lg flex flex-col sm:flex-row items-center gap-space-lg shadow-lg">
<div class="w-20 h-20 rounded-full bg-blue-500/10 border border-blue-500/30 flex items-center justify-center shrink-0">
<span class="material-symbols-outlined text-blue-400 text-[2.5rem]">tune</span>
</div>
<div>
<h3 class="font-headline-sm text-headline-sm text-[#F8FAFC] font-bold mb-1">인간 개입 루프 (Human-In-The-Loop)</h3>
<p class="font-body-sm text-body-sm text-slate-300 leading-relaxed">
                모든 자동화 제안은 수정 가능한 가안(Draft)으로 취급되어야 합니다. 원클릭 실행 취소, 대안 프롬프트 제안, 사용자의 직접 편집 내역을 반영한 재추론 버튼은 사용자가 여전히 조종석에 앉아 있음을 체감하게 만듭니다.
              </p>
</div>
</div>
<p class="font-body-md text-body-md text-[#E2E8F0] leading-loose">
            기술은 복잡해질수록 겸손해야 하며, 인터페이스는 사용자의 직관을 존중하는 방패막이가 되어주어야 합니다. 인공지능이 제공하는 놀라운 생산성을 온전히 누리게 하는 힘은 화려한 비주얼이 아니라 사용자의 자율성을 지켜주는 사려 깊은 설계에 있습니다.
          </p>
</section>

    // Reading Progress Calculation
    window.addEventListener('scroll', () => {
      const docHeight = document.documentElement.scrollHeight - window.innerHeight;
      const scrollPos = window.scrollY;
      const percent = docHeight > 0 ? (scrollPos / docHeight) * 100 : 0;
      const bar = document.getElementById('reading-progress-bar');
      if (bar) {
        bar.style.width = percent + '%';
      }

      // Dynamic TOC Active State Sync
      const sections = ['section-1', 'section-2', 'section-3'];
      let currentSection = '';
      sections.forEach(id => {
        const el = document.getElementById(id);
        if (el) {
          const rect = el.getBoundingClientRect();
          if (rect.top <= 160 && rect.bottom >= 120) {
            currentSection = id;
          }
        }
      });

      sections.forEach((id, idx) => {
        const link = document.getElementById('toc-link-' + (idx + 1));
        if (link) {
          const pip = link.querySelector('span:first-child');
          if (id === currentSection) {
            link.classList.add('text-blue-400', 'font-bold', 'bg-[#1E293B]');
            link.classList.remove('text-slate-300');
            if (pip) {
              pip.classList.add('bg-blue-400');
              pip.classList.remove('bg-slate-600');
            }
          } else {
            link.classList.remove('text-blue-400', 'font-bold', 'bg-[#1E293B]');
            link.classList.add('text-slate-300');
            if (pip) {
              pip.classList.remove('bg-blue-400');
              pip.classList.add('bg-slate-600');
            }
          }
        }
      });
    });
